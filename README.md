# DalaAI

**DalaAI** — команда. **НарядAI** — продукт для кейса №1 Qostanai AI Industry Hackathon 2026: цифровые наряды на ремонт и обслуживание оборудования.

Репозиторий: https://github.com/a4ns/DalaAI

## Текущий статус

Здесь подготовлен организационный bootstrap: правила, стартовые запросы и шаблоны координации. Приложение, API, тесты и CI ещё не реализованы этим комплектом. Требования не считаются выполненными, агенты не считаются запущенными, регистрация команды не считается подтверждённой.

Целевая схема: **3 человека, 3 независимых координатора и 18 исполнителей**. Каждый dot координирует до 6 исполнителей в пределах фактических лимитов своего аккаунта. Общая точка работы — этот репозиторий и согласованный commit.

## С чего начать

1. Прочитайте [AGENTS.md](AGENTS.md) и [START_HERE.md](START_HERE.md).
2. Назначьте людей A/B/C и единственного release owner в [coord/OWNERS.md](coord/OWNERS.md).
3. После принятия комплекта согласуйте полный base SHA с этими правилами. Каждый аккаунт проверяет доступы, среду и лимиты, затем возвращает READY-пакет.
4. Стартуйте согласованные задачи из [coord/TASKS.md](coord/TASKS.md) только после общего подтверждения «Старт согласован».

## Публичность и безопасность

Публичность репозитория выбрана владельцем. Сюда не входят реальные персональные данные, токены, пароли, оригинальный архив конкурса и непубличные данные предприятия. Для демонстрации используются явно помеченные синтетические данные. `.gitignore` помогает избежать случайных файлов, но не заменяет проверку diff перед публикацией.

До реализации нет команды запуска приложения и результатов тестов. Реальные команды и evidence будут добавлены при разработке; наличие планируемой команды в AGENTS.md не означает, что она уже работает.
