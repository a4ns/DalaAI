# DalaAI · НарядAI

Работающий демонстрационный прототип цифровых нарядов на ремонт и обслуживание
для кейса №1 Qostanai AI Industry Hackathon 2026. **DalaAI** — команда,
**НарядAI** — продукт. Данные демонстрации явно синтетические.

## Запуск полного приложения

Нужны Docker Compose и Python 3.12. Из корня репозитория:

```sh
./ops/demo/run.sh
```

Команда поднимает PostgreSQL, API, русский интерфейс, приватное хранилище фото,
отдельный worker и Caddy на одном origin. Локальный адрес —
`https://localhost:8443`; доверие сертификату настраивается обычным способом,
предупреждения браузера не обходятся. Публичного хостинга этот репозиторий не создаёт.

Для **новой** демонстрации с историей:

```sh
DALA_DEMO_FIXTURE_MODE=history ./ops/demo/run.sh
```

Это 540 закрытых синтетических нарядов за июль–сентябрь, 568 попыток и два
действующих тестовых пользователя. Все 17 исторических работников отключены;
444 исторические ссылки на фото не имеют изображений и отмечены в отчётах как
недоступные доказательства. Новые наряды используют реальные загрузки фото.

Профиль выбирается до первой инициализации. Повторный запуск сохраняет базу,
фото и приватную конфигурацию; переключение существующей базы не выполняет
автоматический импорт, восстановление прав или сброс.

Подробности: [полный запуск и настройки](ops/demo/README.md),
[утренний запуск и проверка двух телефонов](ops/demo/MORNING_HANDOFF_RU.md),
[исторический профиль](ops/provision/HISTORY_DEMO.md),
[необязательные общие демо-часы](docs/demo-clock-bootstrap.md).
`make dev` остаётся отдельным небольшим стендом инфраструктуры; для полного
пользовательского сценария используйте команду выше.

## Реализованный сценарий

- Мастер выдаёт наряд; исполнитель принимает, начинает и отправляет результат
- Настоящие тестовые фото проходят проверку и сохраняются приватно; закрытие
  повторно проверяет текущие физические байты
- Отдельный worker сохраняет рекомендацию; окончательное решение принимает мастер
- Без ключа провайдера отображается режим правил. Подключение разрешённого ключа
  после нормальной подготовки включает отдельный ограниченный модельный путь
- Доступны защищённые API аналитики, отчётов и PDF/XLSX. Источники, отсутствие
  оценок и недоступные исторические фото не подменяются положительным результатом
- Необязательный свежий профиль общих часов поддерживает паузу и ускорение
  бизнес-времени. Реальные сроки сессий, фото, аренды заданий и бюджета не меняются

## Проверки и границы

На [347119c](https://github.com/a4ns/DalaAI/commit/347119c47b9a0ec70cd30cbc8bce2a2774a439e0)
прошли восемь автоматических проверок. [PostgreSQL](https://github.com/a4ns/DalaAI/actions/runs/37712740643)
проверяет транзакции, текущие права, общие часы и отдельный worker.
[Compose](https://github.com/a4ns/DalaAI/actions/runs/37712740640) проверяет настоящий
HTTPS, фото → правила → решение мастера, четыре экспорта и повторный запуск.

[Основной браузерный сценарий](https://github.com/a4ns/DalaAI/actions/runs/37712740692)
прошёл в Android-эмуляции: 6 этапов, 11 команд и 13 сохранённых событий.
[Исторический интерфейс](https://github.com/a4ns/DalaAI/actions/runs/37712740639)
прошёл отдельную реальную проверку: 7 этапов, 3 защищённых API-снимка,
3 отказа исполнителю, 540 нарядов / 568 попыток / 444 недоступные ссылки на фото,
без изменения бизнес-данных.

[Отдельный managed-образ на 2d1a407](https://github.com/a4ns/DalaAI/actions/runs/37712260125/job/113100631476)
прошёл совместный профиль истории и часов, тот же рабочий цикл и перезапуск
контейнера с сохранением БД, физических фото и отдельной тестовой записи
бюджетного журнала. Это проверка образа в CI; хостинг у провайдера не выполнялся.

Реальные Android, доставка Web Push/Telegram, живой вызов OpenAI, смешанная
нагрузка и публичное развёртывание ещё не подтверждены. Исходники конфигурации
Render находятся в [ops/managed](ops/managed/README.md); выбор хоста и расходов
остаётся отдельным действием владельца. Сводные показатели не объявляются
модельным анализом или доказанным производственным эффектом.

## Разработка и координация

Проверки Python и контрактов: `make check`. Полная установка точных зависимостей:
`make install`. Фронтенд: `cd frontend && npm ci && npm run check`.
Обязательные интеграционные тесты используют только отдельные одноразовые БД;
отсутствие такой среды не считается успешной проверкой.

- [AGENTS.md](AGENTS.md): правила работы и владельцы изменений
- [START_HERE.md](START_HERE.md): координация команд
- [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md): требования кейса
- [coord/OWNERS.md](coord/OWNERS.md) и [coord/TASKS.md](coord/TASKS.md): распределение задач

Репозиторий публичный по решению владельца. PIN, токены, ключи, cookie,
административные подключения и непубличные материалы предприятия сюда не входят.
Тестовые PIN создаются в приватной конфигурации выбранного оператором хоста;
не копируйте их в Git, публичные логи или запись демонстрации.
