# DalaAI — комплект старта 3×7

Команда **DalaAI**, продукт **НарядAI**, кейс №1. Репозиторий: https://github.com/a4ns/DalaAI, публичный по решению владельца.

1. Это инструкции и шаблоны, а не приложение. Входная точка — [README.md](README.md).
2. [AGENTS.md](AGENTS.md) содержит общую политику; [CLAUDE.md](CLAUDE.md) ссылается на неё. Не перезаписывайте существующие файлы без сравнения и согласования.
3. [START_HERE.md](START_HERE.md): согласуйте точный базовый SHA с принятыми правилами; каждый из трёх людей использует свой запрос A/B/C.
4. До «Старт согласован» координаторы проверяют окружение, доступы и commit. Пароли/токены не передаются между аккаунтами.
5. [coord/OWNERS.md](coord/OWNERS.md) и [coord/TASKS.md](coord/TASKS.md) — стартовые шаблоны. Владельцы, leases и три READY-пакета ещё не подтверждены.
6. [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md) — карта требований со статусом NOT VERIFIED; результаты заполняются только по настоящим проверкам.
7. [REVIEW_NOTES.md](REVIEW_NOTES.md) — источниковые расхождения и вопросы капитану, включая 3-/7-минутный регламент и две оценочные сетки.

Оригинальные конкурсные PDF/DOCX не включены. Храните полученный архив отдельно от публичного репозитория. Файлы других кейсов не являются требованиями или реальными данными «НарядAI».

Комплект сам по себе не запускает агентов, не создаёт доступы/ключи, не активирует платные сервисы и не отправляет заявку. Merge и deploy выполняются только уполномоченным владельцем после отдельного решения.
