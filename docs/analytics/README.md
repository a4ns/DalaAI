# C3: проверяемые определения аналитики

Статус: **офлайн-спецификация и синтетическая проверка арифметики**, не готовый
analytics API, рейтинг сотрудников или измерение предприятия.

- [Определения, источники и ограничения](metric-definitions.md)
- [Синтетические входные факты и независимые ожидаемые ответы](worked-examples.json)
- [Воспроизводимая минимальная проверка](check_examples.py)
- [Приёмка и границы доказательств](acceptance.md)
- [Метрики на зафиксированном экспорте C1](c1-metrics.md)

Запуск из корня репозитория, только стандартная библиотека Python:

```sh
python3 docs/analytics/check_examples.py
```

Скрипт не импортирует backend, не подключается к БД/сети, не читает конфигурацию
секретов, не вызывает модель и не изменяет данные приложения. Он проверяет
правила на маленьком независимом наборе, не подключает генератор C1. Его короткие
символьные идентификаторы удобны для ручной сверки и **не являются UUID API**.
